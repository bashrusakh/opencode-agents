# UI UX Pro Max (UUPM) setup for OpenCode

This is a **manual setup reference**, not an OpenCode runtime policy or custom command. The package installers do not copy it into `~/.config/opencode` or `.opencode/`.

UUPM is optional design intelligence for UI/UX reasoning. It is not a component MCP server and normal UI work does not require installing or updating it.

The commands below reflect the package procedure at this release. If the tooling has changed since this package was published, confirm the current upstream CLI syntax before making changes.

## Procedure

1. Decide whether the intended integration is project-local or user/global. Inspect the existing Git/OpenCode/skill state first and preserve unrelated configuration.
2. Install/use the UUPM CLI:

   ```bash
   npm install -g ui-ux-pro-max-cli
   cd /path/to/project
   uipro init --ai opencode
   ```

   For an explicitly intended global integration:

   ```bash
   uipro init --ai opencode --global
   ```

   Do not silently turn a project-local request into broader global project configuration.
3. After the initializer runs, inspect the exact files/config it created or changed and preserve the upstream-generated structure rather than guessing a local layout.
4. Do not use `--force` or overwrite an existing skill/config blindly. If an installation already exists, compare and update deliberately.
5. For project-local setup, use the structure generated by the OpenCode integration. For global setup, verify the actual target path created by the current CLI/runtime rather than assuming an older path.
6. Do not let setup introduce unrelated fonts/assets/icon or animation libraries, persistent generated design-system artifacts, broad project-wide theming, or product/API/data/routing changes unless those changes are separately intended.
7. Verify both the setup action and OpenCode visibility: confirm the CLI/integration succeeded, confirm OpenCode exposes or can load the resulting `ui-ux-pro-max` skill, and inspect the exact files/config changed. A successful CLI exit alone is not proof that the integration is usable.

## Verification checklist

Confirm:

- intended scope (project or global);
- prior installation state was inspected;
- exact install/update command used is known;
- exact files/config created or changed are understood;
- OpenCode can see/load the resulting `ui-ux-pro-max` skill;
- unrelated project/runtime behavior was not changed.
