# v30.52 beta

## Changes

- `semantic-checkpoint` and `session-evaluator` now explicitly allow the already-required `session-evidence` skill under their OpenCode V2 permission rules. No other permission grants were changed.
- `evals/static-policy-regressions.py` now checks blocker/replacement guards against their concrete active owner/consumer files rather than an aggregate text blob, and checks effective `skill:session-evidence` reachability for both semantic roles.
- `evals/semantic-transition-traces.md` keeps 18 cases but now declares initial/runtime fixtures, injected intermediate output, and earliest expected preservation/stop point for every case. Proposition relation is graded separately from evidence-state transition.
- The Semantic Design Manual release checklist now requires effective reachability of mandatory runtime dependencies and prevents documentation parity from satisfying an active runtime-owner assertion.
