# v30.29 beta

## Purpose

Make the fresh semantic review of the standing prompt corpus a mandatory release gate and apply it to the current root/role instructions.

## Changes

- Adds a release-validation requirement to audit root `AGENTS.md` and every agent file as one semantic corpus against current vendor guidance and observed pack regressions.
- Rewords the root behavioral-contract check from “summarize” to “establish” so it requires the decision without forcing a separate output ritual.
- Consolidates repeated fallback language in `general`.
- Removes the redundant `project-planner` source-edit prohibition already covered by its broader implementation boundary.
- Removes the arbitrary `3–7` next-action quota from `auditor` and the non-accessibility sticky-save-layout reminder from `a11y-reviewer`.
- Replaces a near-verbatim `tester` copy of root shared-path regression coverage with a direct root §7.3 reference.
- Rewords `session-evaluator` to test compliance neutrally instead of assuming it must find a fault.
- Consolidates the owned-PR final-candidate/readiness sequence in `code-orchestrator` under the existing PR follow-up section.
- Cleans README/changelog release prose and moves the changelog overview directly under its title.
