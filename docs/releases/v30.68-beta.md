# v30.68 beta — calibrated role-contract audit v3

## Purpose

v30.68 freezes a stricter but better-calibrated contract/protocol checker before any runtime-role repair. It removes the remaining size/sparsity heuristic from status decisions and distinguishes a non-executable role from an executable role with a material contract gap.

## Audit changes

- prompt length is diagnostic only and can no longer create `REVIEW`;
- missing foundational scope/procedure/result semantics or an essential profile core-loop capability -> `FAIL`;
- a material secondary capability gap in an otherwise executable role -> release-blocking `REVIEW`;
- PASS additionally requires a characteristic false-success/adversarial defense appropriate to the role profile;
- action/decision counts are diagnostic review evidence rather than standalone proof of non-executability;
- synthetic self-tests preserve compact executable discovery and distinguish audit-reconciliation REVIEW from a non-executable role;
- adds ST-52 for severity calibration.

## Frozen pre-repair result

Against runtime agent contracts unchanged from v30.67, audit v3 reports:

- `PASS=10`
- `REVIEW=1` (`auditor`)
- `FAIL=6` (`a11y-reviewer`, `devops`, `general`, `ui-auditor`, `ui-implementer`, `ui-planner`)

This exactly matches the independent manual audit. v30.68 is therefore an **audit baseline / not promotion-ready**, not a repaired runtime pack.
