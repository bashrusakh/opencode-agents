# v30.42 beta

## Changed

- Adds a material-decision visibility contract: when new evidence determines a materially different next course of work, the resulting decision state and relevant basis must be visible before the consequential next step.
- Keeps that visibility bounded: evidence that only confirms an already-visible path does not require another update, and routine tool/substep narration remains suppressed.
- Requires concise, readable Markdown for free-form agent text, including user-facing messages, specialist assignments, handoffs, delegated reports, and public artifacts, unless the destination explicitly requires another format.
- Requires `code-orchestrator` assignments to stay stage-relevant and compact rather than carrying accumulated workflow-history dumps.
- Extends `session-evaluator` to detect silent material decision adoption from specialist/tool evidence.
- Aligns `output-formatting` with the root Markdown contract for terminal/chat destinations.
