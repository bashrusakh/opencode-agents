# v30.89 beta — whole-scope review and reconstructable handoffs

## Summary

v30.89 consolidates two production-session lessons plus the GrayMatter/fresh-review edge observed under v30.87. The workflow owner must supply a whole authoritative acceptance model for a whole-PR gate, preserve reviewer qualifiers instead of strengthening slice evidence, and keep parent technical inferences non-binding until authority or discriminating end-to-end evidence establishes them. Specialist assignments are also required to be minimally sufficient and reconstructable rather than dense session dumps.

Fresh independent judgment remains compatible with an enabled GrayMatter integration. The new distinction is lifecycle ownership: parent-task continuity belongs to the workflow owner. A fresh reviewer does not run the parent's checkpoint/memory recovery as startup context. If task-specific prior investigative steering is already injected or intentionally retrieved, the fresh context is still contaminated and the reviewer stops as before.
