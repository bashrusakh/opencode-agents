# v30.55 beta

## Changes

- `reviewer` now checks composition of independently meaningful projections, annotations, classifications, or refinements that can coexist on the same object. Isolated-path success no longer suffices when order, early return, or branch composition can erase or bypass another material dimension.
- `reviewer` now operationalizes the existing root evidence-fidelity rule for cross-layer accepted domains: the owning contract/validator remains authoritative, while convenience parsers, normalizers, mocks, fixture generators, client validators, or local canonical representations cannot silently narrow the domain or introduce an unstated representation precondition.
- `reviewer` fallback/recovery review now checks both control-flow reachability and the semantic success postcondition of earlier stages whose reported success suppresses fallback. A successful API/syscall/helper return is not proof that the required usable state/artifact was produced.
- The temporary semantic-transition suite expands from 25 to 27 scenarios. ST-26 covers independent projection/refinement composition; ST-27 covers fallback suppression by false semantic success. ST-24 remains the accepted-domain regression and now has an explicit runtime reviewer obligation rather than eval-only coverage.
- Root task-semantic authority/evidence semantics are unchanged; `AGENTS.md` changes only its version marker. No new state/lifecycle owner is introduced.

## Validation status

Static policy regressions pass. Three mutation probes independently remove the projection/refinement composition, authoritative-domain preservation, and fallback semantic-success reviewer guards; each mutation correctly makes the structural harness fail. Fresh isolated replay of the 27 semantic transition scenarios remains separate behavioral evidence and is not claimed by this release.
