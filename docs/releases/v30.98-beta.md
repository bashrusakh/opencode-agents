# v30.98 beta — conditional UI routing residency and workflow-path validation

## Summary

v30.98 removes the code-to-UI direction discriminator and detailed UI handoff procedure from every resident `code-orchestrator` session. The new non-autoinvoked `ui-routing-control` skill owns the conditional bridge into the UI domain, while `ui-orchestrator` remains the owner of internal UI stage selection/reconciliation and `ui-implementer` remains the focused mutation owner.

The release also adds a whole-workflow path gate that checks activation timing plus producer→consumer information contracts across 18 end-to-end routes.

Permissions/frontmatter and bundled third-party/vendor skill content are intentionally unchanged.

## Runtime fixes found by the end-to-end pass

- Initial bugfix routing now passes the debugger the exact symptom/reproduction or strongest failure evidence, governing expected behavior/invariant, affected behavior boundary, and target/mutation identity while keeping suspected remediation non-binding.
- Delegated multi-stage UI routing now explicitly returns leaf evidence to `ui-orchestrator` when more UI stage selection/reconciliation remains; `code-orchestrator` does not infer the remaining UI chain itself.

## Evaluation changes

- `ui-routing-control` is a first-class conditional pack skill with `opencode/autoinvoke: "false"` and a dedicated residency audience.
- semantic ownership adds `code_to_ui_routing_boundary` and composes it with generic delegation/routing/decision-space contracts.
- conditional skill-mediated UI edges are attributed to `code-orchestrator` for topology and handoff audits without restoring UI procedure to the resident role prompt.
- `workflow-path-audit` + selftest cover 18 routes and fail when required activation timing or handoff evidence disappears.
- ST-138..ST-141 cover conditional UI residency, delegated UI reconciliation, bugfix debugger handoff fidelity, and end-to-end workflow composition.

Fresh isolated behavioral replay of ST-138..ST-141 is not claimed in this release, so v30.98 remains beta.
