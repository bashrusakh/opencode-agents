# v30.44 beta

## Changed

- Makes user adoption of referenced material proposition-scoped: normative outcomes, acceptance criteria, and explicit constraints are separated from diagnoses/evidence, proposed mechanisms, rationale/examples, and optional recommendations/fallbacks.
- Keeps selected implementation mechanisms classified as implementation choices unless authority actually requires them, and separates adequacy from authority in checkpoint reports and orchestrator handoffs.
- Adds a canonical evidence-state distinction for material actions/outcomes: intended/planned, reported completion or failure/uncertainty, and independently verified completion or failure/uncertainty.
- Updates `session-evaluator` to preserve reported state when independent execution evidence is unavailable and to identify material retrospective state-characterization errors separately from evidence gaps or execution/instruction defects.
- Updates the Semantic Design Manual with the same proposition-scoped authority and evidence-state methodology.
