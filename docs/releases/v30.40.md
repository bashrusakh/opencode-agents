# v30.40

## Changed

- Relayers shared root policy using the Semantic Design Manual: permanent context keeps global semantic invariants, while conditional integration/procedure detail moves behind skills.
- Makes GrayMatter recall relevance-triggered instead of mandatory on every task; detailed memory mechanics move to `graymatter-memory`.
- Removes the static specialist/advisory skill routing table from root and uses the actually exposed skill catalog/activation metadata.
- Keeps the durable-planning trigger and reconstructable-state contract in root while moving the default file layout/procedure to `persistent-planning`.
- Narrows the temporary `session-evaluator` diagnostic harness to terminal successful outcomes: satisfied session goal or final owned-PR readiness.
- Condenses mutation guidance to a target-bounded, understood transformation plus resulting diff/state inspection.
- Adds the conditional `graymatter-memory` and `persistent-planning` skills, bringing the bundled inventory to 20 skills.
- Promotes the validated v30.40 beta candidate to stable.
