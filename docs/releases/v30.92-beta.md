# v30.92 beta — typed semantic domains and root/orchestrator placement

## Summary

v30.92 closes the control-plane gaps exposed after v30.91 without changing agent permission/frontmatter policy.

The release separates three concerns that were previously conflated:

1. **semantic ownership** — who canonically defines a shared contract;
2. **typed semantic domain integrity** — what durable state/verdict/relation literals mean;
3. **section placement** — whether a material root/orchestrator section belongs at the shared or role-local layer.

## Runtime semantic corrections

- `unverified` remains an evidence/verification status only. `trajectory-auditor` now returns `insufficient-evidence` when primary history is insufficient for its workflow judgment; unsupported underlying propositions remain `unverified`.
- `code-orchestrator` consumes root-owned fresh-review isolation by reference rather than defining the generic capability-vs-exposure/memory-contamination policy again.
- review activation/cadence remains root-owned; the orchestrator keeps code-specific stable-diff/risk specialization and exact verdict-boundary consumption.
- user-decision binding remains root-owned; the orchestrator owns when/how to ask a self-contained question and how to preserve a provenance receipt.
- publication authorization remains root-owned; the orchestrator activates the root gate rather than maintaining a weaker local authorization formula.
- failed-root-cause reset remains root-owned; the orchestrator specializes the diagnostic recheck dimensions after that trigger fires.
- root request normalization now routes issue/ticket/report outcomes without carrying a detailed issue pipeline. Detailed issue/report mechanics are colocated with existing-PR mechanics under `code-orchestrator` `Workflow behavior`.
- the owned-PR Draft/Candidate/Ready lifecycle remains in `skills/pr-readiness/SKILL.md`; neither root nor orchestrator redefines that state machine.

## Evaluation changes

Adds:

- **ST-121** — evidence-status literal must not become a workflow verdict;
