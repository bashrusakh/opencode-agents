# v28.33

v28.33 closes the remaining PR state-identity gap: Candidate HEAD can stay unchanged while its base moves.

Final PR evidence is bound to:

```text
Base SHA + Candidate HEAD
```

Refresh Base SHA before final review, before PR publication, and before Ready. If it moved, recompute the effective diff and affected integration context. Reuse existing evidence only when that context is proven unchanged; otherwise refresh affected validation/review.

Pushing the exact reviewed Candidate HEAD still does not by itself require another review.
