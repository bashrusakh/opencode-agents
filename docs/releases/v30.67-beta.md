# v30.67 beta — adversarial role-contract audit v2

## Purpose

v30.67 does not repair runtime roles. It repairs the release checker after v30.66 showed that keyword-style structural evidence could still grant overly easy role-contract PASS results.

## Audit changes

- replaces loose dimension presence with role-local method analysis plus profile-specific core-loop checks;
- method-oriented dimensions no longer pass merely because a word appears in `Result`;
- measures action-bearing procedure lines, conditional decision rules and sequence cues as evidence, not as a length quota;
- introduces release-blocking `REVIEW` when a compact routed role has enough structural matches to avoid hard FAIL but too little role-local evidence for an honest automatic PASS;
- adds synthetic anti-gaming fixtures for keyword stuffing, missing operational diagnostic isolation, compact-but-executable discovery, and producer-side recipe contamination;
- adds ST-49…ST-51 for keyword stuffing, compact-role preservation and profile-specific core-loop adequacy.

## Current result

The tightened checker reports `FAIL=7`, `REVIEW=2`, `PASS=8`; therefore the package remains **not promotion-ready**. Runtime agent semantics are unchanged from v30.66/v30.65.
