# v30.69 beta — role-contract and handoff repair

## Purpose

v30.69 repairs the runtime roles identified by the frozen v30.68 contract audit. The v30.68 `contract-protocol-audit.py` v3 logic is not loosened or retuned for these fixes.

## Runtime contract repairs

- `a11y-reviewer`: exact target/mode binding, affected-interaction derivation, representative preserved/negative states, evidence/coverage limits and stale-verdict semantics.
- `auditor`: bounded specialist assignments plus evidence-based reconciliation of conflicting/partial specialist outputs without voting or authority laundering.
- `devops`: observed symptom/current state → fault-layer isolation → hypothesis → exact authorization → reversible mutation → original-symptom/postcondition verification.
- `general`: bounded research method with authoritative-source use, fact/inference/hypothesis separation, alternative explanation check, unknowns and specialist handoff boundary.
- `ui-auditor`: current screen/user-job/ownership binding, evidence-backed findings, preservation/counterexample check, confidence/coverage/stop semantics.
- `ui-implementer`: pre-edit UI owner/state model, proportional changed+preserved state map, final diff/state self-review and falsification before return.
- `ui-planner`: actual current frontend ownership, product-vs-mechanics separation, real alternatives/tradeoffs, authority stop, ordered plan plus verification/regression map.

## End-to-end handoff repairs

- `code-orchestrator` now states role-specific minimum handoff semantics for DevOps, general research and direct UI implementation.
- `ui-orchestrator` now constructs leaf handoffs for UI audit/planning/implementation/a11y from established outcome/state/evidence rather than forwarding solution framing.
- `auditor` now constructs bounded specialist assignments, keeps DevOps read-only inside audit, preserves fresh independent judgment contexts, and prevents a general fallback from replacing a protected stage.

A separate `role-handoff-audit.py` / selftest is release-blocking. It checks 11 real edge profiles and synthetic negative cases such as recipe-shaped DevOps fixes, unbound a11y review, preselected UI planning, and unbounded audit delegation.
