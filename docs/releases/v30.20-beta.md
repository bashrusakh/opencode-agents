# OpenCode Agent Pack v30.20 beta

## Scope

Deeper role-local prompt consolidation built on v30.19 beta. This is deliberately a separate rollback point because it removes more repeated role text than v30.19.

## Changes

- Compacts the `code-orchestrator` implementation-prohibition block to the role-specific invariant plus canonical root §2.5 instead of repeating the full alternate-editor/fallback policy.
- Compacts the reviewer finding-classification list without removing any category or changing verdict semantics.
- Preserves v30.18 semantic framing and v30.19 canonical policy residency while reducing role-local prompt weight.
- Changes no topology, permissions, routing, gates, model policy, planner activation, installer behavior, or skill inventory.

## Safety intent

The code-orchestrator still has an explicit role-local statement that it never implements repository changes; only the duplicated mechanics are delegated to canonical root §2.5. The reviewer still has all six finding classes semantically, but no longer repeats them as a vertical list.
