# v30.30 beta

## Purpose

Remove the unnecessary package-owned session-trace wrapper and let the experimental `session-evaluator` use OpenChamber's native session history surface directly.

## Changes

- `session-evaluator` uses the OpenChamber `openchamber` tool only for `session.list` and `session.messages`.
- It reconstructs the completed `code-orchestrator` workflow from session metadata and `parentID` relationships, excludes evaluator sessions, and prefers child-session history over parent summaries.
- The audit remains focused on framing, acceptance, scope, ownership, invariants, fix level, delegation, authority propagation, role/gate compliance, and instruction gaps. Raw tool-call output is not required when session messages already establish the material decision.
- Removes `tools/session_trace.js`.
- Global and project-local installers back up and remove the obsolete package-owned `session_trace.js` when upgrading from v30.27-v30.29.
- README runtime references now point to the OpenChamber session-control surface used by the evaluator.
