# v30.26 beta

## Change

Root section 2.2.1 now makes one classification explicit: a material decision about framing, required behavior, scope, ownership, invariant, or fix level is itself a claim for that section.

The release does not add a new self-review stage. Existing claim-authority, evidence, real-behavior, counterexample, reverse-inference, and hypothesis rules apply to these decisions.

## Intent

Prevent a workflow from treating its own scope/fix-level/invariant choice as exempt from the evidence standard while avoiding mandatory re-check loops for routine decisions.
