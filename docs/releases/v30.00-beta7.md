# v30.00-beta7 — zero-command runtime

v30.00-beta7 removes the final custom-command layer from the package.

## Runtime command rule

The package uses semantic natural-language routing plus agent contracts as its workflow interface. A slash command that merely restates an intent is a parallel routing layer and is not shipped. Environment/setup procedures that are not coding workflows belong in ordinary documentation rather than OpenCode runtime commands.

## Changes

- Removes `/ui-mcp-setup` and `/ui-uupm-setup`; package custom-command count is now **0**.
- Preserves their useful procedure text as human documentation:
  - `docs/ui_mcp_setup.md`
  - `docs/uupm_setup.md`
- These docs are not runtime policy, have no mandatory model consumer, and are not copied by either installer.
- Natural-language coding/workflow routing remains entirely resident in `AGENTS.md` and owning agent contracts.
- `AGENTS.md` changes only one stale phrase: workflow routing now selects the right **role or workflow**, not a package command.

## Upgrade hygiene

Both installers know all 21 historical package-owned command filenames, including the two removed in this release. Existing matching files are backed up and removed during upgrade. Unrelated user/project commands are not removed.

Historical package-owned runtime policy/setup docs from earlier betas are also pruned by exact filename; unrelated docs are preserved. Package documentation is not installed into OpenCode runtime.

## Unchanged behavior

Agents, skills, semantic request routing, approval gates, claim authority, state identity, implementation rules, verification, PR provenance, Draft/Candidate/Ready lifecycle, review semantics, and UI role behavior remain unchanged from beta6 except the stale command-layer wording noted above.
