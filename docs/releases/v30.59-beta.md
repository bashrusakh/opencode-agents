# v30.59 beta

## Changes

- `reviewer` restores the v28.35 delegate-first contract: every code/diff/commit/branch/workspace/PR review loads `open-code-review-delegate` after authoritative target/effective-diff establishment and follows its deterministic preflight before substantive host review reasoning.
- Deterministic delegation is not a risk/usefulness heuristic. The owning skill determines compatibility/availability; when delegation is unavailable, reviewer records that condition and uses native review preflight.
- Managed `open-code-review` / `ocr review` remains a separate independent-model escalation used only when user/project policy requires it or when it materially improves confidence.
- `open-code-review-delegate` itself is unchanged: target identity remains reviewer-owned, delegate output remains deterministic scaffolding/evidence, and unexplained scope mismatch still blocks full-coverage claims.
- ST-31 is added so compatible deterministic delegation cannot silently become discretionary again. Static policy regressions now require the reviewer-owned mandatory activation/fallback boundary.
- Root task semantics and all other role/skill contracts are unchanged apart from the pack version marker.

## Validation status

Static structural regressions, mutation probes for the restored delegate-first reviewer contract, and package checks pass. Fresh isolated behavioral replay of ST-01…ST-31 remains separate evidence and is not claimed by this release.
