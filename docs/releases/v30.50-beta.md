# v30.50 beta

## Changed

- Adds `evals/semantic-transition-traces.md` as a release/evaluation suite for tracing material propositions across the complete applicable request-to-final-report workflow.
- Each material transition is graded on both the delta and its provenance: what changed, why it changed, the source/cause, and whether sufficient task-semantic authority/evidence exists for that exact transition.
- Adds 16 synthetic cases covering qualifier loss, decision-space narrowing, unsupported substitution, legitimate refinement, skill accretion/composition, invalid verification artifacts, retry drift, uncertainty resolution, non-gating diagnostics, authorized closed alternatives, project-local constraints, and final-report overstatement.
- Includes two synthetic regressions derived from observed real failure classes without copying repository-, issue-, provider-, status-, or implementation-specific wording: (1) source adoption plus reported-vs-independently-verified state; (2) qualifier loss while translating a proposition into verification evidence.
- Extends the Semantic Design Manual and README release validation to require isolated/fresh replay rather than treating static existence or authoring-context inspection of the eval cases as a pass.

## Scope

- This release adds evaluation infrastructure rather than a new runtime agent, gate, or verification stage; agent/skill behavior is not modified.
