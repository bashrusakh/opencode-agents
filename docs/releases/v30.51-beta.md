# v30.51 beta

## Changes

- All 17 pack-owned agents now use the OpenCode V2 ordered `permissions` rule schema. Legacy `permission`/`task` frontmatter was translated to V2 `permissions`/`subagent`; the migration is schema-only with respect to the existing permission-policy intent.
- Task-semantic authority now distinguishes **evidence that blocks an established path** from **authority for a materially different replacement**. A blocker may activate a replacement only when that replacement was already established as a conditional alternative, or when separate proposition-scoped authority is obtained.
- `project-planner` and `ui-orchestrator` now keep evidence/adequacy separate from material product/design authority while preserving evidence-driven implementation discretion.
- `pr-readiness` is the canonical owner of the reusable owned-PR Draft/Candidate/Ready lifecycle; `git-provenance` remains the ref/base/head identity owner and UI orchestration consumes rather than restates readiness sequencing.
- `resource-lifecycle` now owns temporary-resource ownership/transfer/failure/terminal-state mechanics; root retains only the completion invariant, activation, and cleanup gates.
- Adds `ui-component-sources` as the single pack-owned owner of the existing named UI component-source/UUPM integration policy. The source order itself is unchanged; generic UI roles load/consume the skill instead of embedding provider/tool names.
- `evals/semantic-transition-traces.md` now has 18 cases, adding evidence-vs-product-choice and pre-authorized-conditional-fallback coverage.
- Adds `evals/static-policy-regressions.py` for OpenCode V2 schema and cross-layer ownership/leakage regression guards. Static guards are not a substitute for isolated semantic replay.

## Validation status

Static/package validation passes in the release build. Fresh isolated replay of the 18 semantic-transition scenarios remains a separate required behavioral verification step; this release does not treat scenario definitions or authoring-context inspection as replay evidence.
