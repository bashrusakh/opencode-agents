# v30.31 beta

## Purpose

Make the experimental `session-evaluator` exhaust OpenChamber's native session listing before concluding that descendant-session evidence is unavailable.

## Changes

- Starts session discovery with `session.list` using `limit: 1000`, `all: true`, and `withStatus: true` instead of relying on the default 10-session result. `all: true` includes archived sessions; the explicit limit controls result size.
- Allows `session-evaluator` to read only OpenCode's managed `~/.local/share/opencode/tool-output/*` spill directory so oversized `session.list` / `session.messages` results can be consumed instead of failing on `external_directory`.
- Reconstructs the completed workflow through `parentID` links, then reads each participating session with `session.messages` using `all: true` and no `limit`, `last`, or `lastAssistant`.
- Excludes diagnostic evaluator sessions from the audited tree.
- When the expanded listing still cannot recover a branch, marks that branch `unverified` and does not replace missing child evidence with the orchestrator's summary.
