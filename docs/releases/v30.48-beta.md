# v30.48 beta

## Changed

- Replaces the remaining evaluator-specific `PASS`/`BLOCK` proof labels with proposition-based evidence semantics.
- Generalizes semantic terminology validation from incidental presentation examples to any origin-specific literal semantic state/value.
- Requires canonical literal states to be either pack-defined semantic classes/enums or exact external literals whose representation is itself contractual; otherwise policy must use the underlying meaning.
- Adds a rename-counterfactual release check so reusable rules remain complete when incidental local status/value names change.
