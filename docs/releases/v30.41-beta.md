# v30.41 beta

## Changed

- `code-orchestrator` now passes the current parent session ID to `semantic-checkpoint` / `session-evaluator` when that ID is already known from current context or tool output, and also passes material participating child-session IDs already known from task results.
- The handoff states whether the supplied participating-session set is complete or partial when that distinction is established.
- `semantic-checkpoint` and `session-evaluator` use supplied session IDs directly and do not call `session.list` to rediscover them.
- `session.list` is now fallback discovery only when a required session identity or parent/child relationship is missing or the supplied participating-session set is partial.
