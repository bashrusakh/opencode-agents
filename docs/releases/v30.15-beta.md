# v30.15 beta

Retires the experimental external context-compaction integration from v30.14 beta.

## Why

The integration's conceptual goal was reasonable, but its real-world latency was unacceptable for the intended coding workflow. Keeping an optional runtime policy whose practical cost makes it unattractive would create dead guidance and stale activation paths.

## Changes

- Removes the bundled context-compaction workflow skill and its root activation/trigger semantics.
- Removes the associated setup/reference document and the dedicated historical beta release note for that experiment.
- Removes the integration from the README skill inventory, external-source list, and documentation map.
- Adds exact upgrade cleanup for the retired package-owned skill directory in both global and project-local installers. Cleanup backs up only that exact legacy directory and leaves unrelated skills untouched.
- Does not uninstall or mutate external OpenCode plugins/configuration; those are outside package-owned runtime state and remain separately user-controlled.

## Unchanged

- v30.14 native edit/patch mutation semantics and role-local salience.
- Agent routing, goal/path ownership, role topology, permissions, gates, provenance, PR readiness, and verification policy.
- All remaining bundled skills and documentation/setup surfaces.
