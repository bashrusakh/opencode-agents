# v30.100 beta

Terminology-only release over v30.99. Four pack-controlled conditional skills were renamed without changing their semantic ownership, activation, audience, or runtime procedure:

- `workflow-entry` -> `workflow-control`;
- `implementation-contract` -> `change-contract`;
- `terminal-semantic-eval` -> `session-evaluation-control`;
- `code-host-workflow` -> `repository-workflow`.

Active role/skill references, control manifests, eval specifications, selftests, and capability IDs use the new names. Historical release records are intentionally unchanged. Agent permission/frontmatter and vendor skill subtrees are unchanged.
