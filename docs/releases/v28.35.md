# v28.35

v28.35 changes code-review execution without changing reviewer authority or PR readiness semantics.

## Delegate preflight is first

For code/diff/commit/branch/workspace/PR review, a compatible local OCR delegation path now runs before host reasoning:

```text
authoritative target/state
  -> authoritative changed set
  -> ocr delegate preview
  -> reconcile reviewable + excluded entries
  -> ocr delegate rule
  -> host @reviewer full pass
```

Delegation calls no OCR-side LLM, needs no OCR provider/API key, and does not require `ocr llm test`. If delegation is unavailable, reviewer uses native scope/rule discovery instead.

## Coverage cannot shrink silently

OCR selection is scaffolding, not target authority. Reviewer reconciles every delegate `(path,status)` entry against the authoritative workspace/range or Base SHA + Candidate HEAD changed set. Excluded entries stay visible with reasons, and behaviorally relevant excluded files may still require host inspection. An unexplained mismatch blocks `Coverage: full PR`.

## Managed OCR is escalation, not default

`ocr review` remains available as an independent second-model pass, but it now runs after host review only when user/project policy requires it or when it materially improves confidence for high-risk/complex/uncertain changes. External-sharing and OCR LLM checks apply to managed OCR, not delegation.

A managed OCR quota/rate/provider failure does not erase already-complete host-review evidence. It blocks the overall review only when managed OCR itself was explicitly required.

## Skill updates

- `skills/open-code-review/SKILL.md` is replaced with the supplied current command contract, including current review target/output/model/budget/session semantics.
- `skills/open-code-review-delegate/SKILL.md` is added for deterministic `preview` + `rule` preflight, coverage ledger, target reconciliation, runtime `--format` capability fallback, and safe background handling.
- The bundle does not assume the proposed `ocr delegate task` command exists; use it only if the installed CLI explicitly exposes it.

## Unchanged guarantees

- `@reviewer` remains read-only and owns the final judgment.
- v28.30 failed-fix reset, v28.31-v28.33 freshness/state/base identity, and v28.34 outcome-owned fix boundary remain intact.
- Managed OCR is not a universal Ready gate.
