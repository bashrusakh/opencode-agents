# OpenCode Agent Pack v30.66 beta

## Purpose

v30.66 changes the **release/evaluation harness**, not runtime role semantics. The goal is to make checks discover missing role contracts and cross-role incompatibilities instead of merely confirming that current instructions contain expected phrases.

## New release evidence model

Three classes are independent:

1. **Static / retention** — schema, dependency, known invariant and rule-retention checks.
2. **Contract / protocol** — role executability and producer → transformer → consumer compatibility.
3. **Behavioral replay** — isolated end-to-end semantic traces under the actual model/runtime.

A release may not claim one class passed because another did.

## Contract / protocol audit

`evals/contract-protocol-audit.py`:

- discovers routed role edges from root and orchestration surfaces;
- classifies every agent under a generic capability profile;
- checks whether each routed substantive role has role-local scope/input semantics, executable procedure, evidence/self-check, stop/escalation, and result semantics proportional to the capability;
- checks mutation consumers and orchestrators for recipe/authority laundering across handoffs;
- treats unknown/unclassified routed roles as findings;
- deliberately says that structural matches are not proof of semantic correctness.

The criteria are profile-level rather than current-release exact phrases. `evals/contract-protocol-selftest.py` uses synthetic contracts to prove that a thin implementation role and a contaminating producer output are rejected without deleting any current-pack sentence.

## Semantic regression suite

Adds:

- **ST-47** — a routed substantive role must have an executable role-local contract;
- **ST-48** — per-file correctness must not substitute for producer→transformer→consumer protocol compatibility.

The suite therefore contains 48 scenarios. Fresh isolated behavioral replay remains required before any replay PASS claim.

## Promotion status

**NOT PROMOTION-READY by design.**

An unresolved generic audit finding remains a red gate. Do not add role-specific exclusions only to turn the release green.
