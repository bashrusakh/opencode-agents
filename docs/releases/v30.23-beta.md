# OpenCode Agent Pack v30.23 beta

## Scope

Prompt-language cleanup built on the v30.22 authority-provenance semantic fix.

## Prompt-design basis

This release applies the current OpenAI prompting guidance at:

<https://developers.openai.com/api/docs/guides/latest-model>

The relevant guidance is to keep prompts lean, state each instruction once, use plain language and precise verbs, keep autonomy/approval boundaries compact, and validate prompt changes on representative tasks. The cleanup follows those recommendations only where they improve clarity without weakening a contract.

## Changes

- Simplifies root `AGENTS.md` with shorter sentences and direct verbs while keeping defined technical terms where they distinguish real workflow states or authority boundaries.
- Rewrites root §2.2.1 so the authority rule is direct: derived reasoning is evidence until a material requirement traces to established user intent, project rules, or a necessary consequence.
- Keeps necessary cross-layer implementation possible when the established outcome cannot be met without it, while preventing an inferred stronger rule from authorizing its own downstream scope.
- Compacts `code-orchestrator` around stage ownership, delegation, authority checks, review/test cadence, escalation, and PR lifecycle decisions.
- Compacts `reviewer` around exact target identity, authority/evidence separation, affected-rule completeness, whole-PR review, and verdict evidence.
- Simplifies all other role prompts individually, removing root-policy restatements and dense phrasing while keeping their role-specific capability, scope, verification, escalation, and publication behavior.

## Audit method

The language cleanup was reviewed in two passes:

1. root `AGENTS.md` against the current OpenAI prompt guidance and the pack's existing semantic/adversarial criteria;
2. every agent file separately against its v30.22 role contract, with role-specific semantic anchors and cross-file duplicate checks.

Detailed validation and agent-by-agent audit reports are distributed beside the release archive rather than loaded into runtime prompt context.
