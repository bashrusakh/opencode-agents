# v30.49 beta

## Changed

- Distinguishes **task-semantic/product authority** from instruction/action precedence: safety/runtime/tool ceilings, role boundaries, gates, and workflow policy constrain permissible action and claims but do not become product acceptance criteria.
- Explicitly exempts the temporary terminal `session-evaluator` diagnostic from required-stage failure semantics; diagnostic unavailability may be reported but does not reopen or block an already-established terminal outcome.
- Adds `session-evidence` as a conditional procedural skill owning OpenChamber `session.list` / `session.messages` completeness, pagination, supplied-ID reuse, participating-session discovery, and materialized-output handling. `semantic-checkpoint` and `session-evaluator` now retain only their semantic evidence requirements.
- Reduces `reviewer` review-integration wording to role-owned semantics and delegates CLI/provider mechanics to the existing review integration skills.
- Makes `pr-readiness` the single owner of the reusable Draft/Candidate/publication/readiness lifecycle sequence; root and orchestrator retain activation, authorization, evidence, and consumption responsibilities without repeating the state machine.
- Strengthens the Semantic Design Manual and README release checks with cross-layer ownership mapping, explicit gating-class consistency, semantic-role mechanism-leakage checks, and ownership/provenance triage so external/vendor surfaces are not rewritten as if they were pack-owned canonical policy.

## Intentionally unchanged

- External/vendor specialist skills are not rewritten; root precedence continues to prevent a skill recommendation from creating task authority, new dependencies, strict modes, or coverage gates.
- UI source-ordering/UUPM policy is not changed in this release because the independent audit did not establish its provenance well enough to justify removal or generalization.
- Existing semantic contracts for proposition-scoped authority, qualifier preservation, semantic substitution, decision-space preservation, evidence fidelity, and reported-vs-verified state remain unchanged.
